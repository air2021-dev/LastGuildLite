# 📢 마지막 길드 업데이트 내역
### ver 1.1.0 (26.10.15)
## 🛡️ 전선 및 포지션 시스템 추가
- 방어선에 전열 / 후열 포지션이 추가되었습니다.
- 같은 직업이라도 배치 위치에 따라 능력치와 운용 방식이 달라집니다.
- 전열과 후열을 활용해 보다 다양한 방어 진형을 구성할 수 있습니다.
- 도시 레벨에 따라 전선과 전체 배치 가능 인원이 확장됩니다.
## ⚔️ 직업별 포지션 특성 추가
- 전사
  - 전열에서는 방어력이 상승하여 탱커 역할에 특화됩니다.
  - 후열에서는 공격력이 감소하지만 자연회복력이 증가합니다.
- 궁수
  - 전열과 후열에 따라 공격·방어·회복 성능이 달라집니다.
- 마법사
  - 전열에서는 공격력이 크게 증가하지만 방어력이 크게 감소합니다.
  - 높은 위험을 감수하고 강력한 화력을 낼 수 있습니다.
- 사제
  - 전선에 배치하면 같은 방어선의 모험가 회복을 지원합니다.
  - 전열/후열 위치와 관계없이 사제의 기본 치유 능력은 유지됩니다.
## ✨ 시너지 시스템 개선
- 직업 조합에 따라 다양한 시너지가 활성화됩니다.
- 활성화된 시너지를 방어선에서 직접 확인할 수 있습니다.
- 시너지 시스템을 데이터 기반으로 변경하여 새로운 조합을 쉽게 추가할 수 있도록 개선했습니다.
## ❤️ 회복 시스템 개선
- 대기 중인 모험가는 웨이브마다 체력을 회복합니다.
- 방어선에 배치된 모험가도 일정량의 자연회복이 가능합니다.
- 전열/후열에 따라 자연회복 효율이 달라집니다.
- 사제가 같은 방어선에 있을 경우 추가 회복 효과를 받을 수 있습니다.
## 📊 웨이브 결과 개선
- 웨이브 종료 후 결과 화면에서 다음 내용을 확인할 수 있습니다.
  - 받은 피해
  - 회복량
  - 획득 경험치
  - 레벨업
  - 후퇴
  - 사망
  - 획득 골드 및 보상
## 💰 골드 / 💎 보석 수급 개선
- 웨이브 진행을 통해 골드를 획득할 수 있도록 보상 구조를 개선했습니다.
- 골드와 보석의 획득 경로를 구분했습니다.
- 골드는 일반적인 길드 운영 자원으로,
  보석은 보다 희귀한 성장 자원으로 활용되도록 조정하고 있습니다.
## 🗺️ 퀘스트 시스템 확장 준비
- 퀘스트를 여러 종류로 확장할 수 있도록 구조를 개선했습니다.
- 퀘스트에 다음 요소를 설정할 수 있게 되었습니다.
  - 퀘스트 종류
  - 요구 전투력
  - 수행 웨이브
  - 골드 보상
  - 보석 보상
  - 경험치 보상
  - 필요 인원
  - 필요 직업
- 향후 일반 / 정예 / 보스 / 다인 퀘스트 등으로 확장될 예정입니다.
## 🖥️ UI 개선
- 방어선 UI를 가로형 전장으로 개편했습니다.
- 도시 → 최종 방어선 → 외곽 방어선 → 마왕군 진입 방향을 보다 직관적으로 확인할 수 있습니다.
- 상단 HUD에서 도시 HP와 주요 전투 정보를 쉽게 확인할 수 있습니다.
- 화면을 스크롤해도 필요한 전투 정보를 확인할 수 있도록 개선했습니다.
- 기존 브라우저 alert() 대신 게임 전용 팝업 시스템을 추가했습니다.
